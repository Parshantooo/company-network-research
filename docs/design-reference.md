# Interface and typography

The explorer leads the page, followed by the research explanation and source notes. The full-network overview groups companies by sector. Selecting a company reveals its relationships; neighborhood mode provides a focused view. Locations and node sizes carry no statistical meaning.

The page uses navy text, a cool gray background and purple for focus and trace highlights. Body text uses self-hosted Roboto; headings use self-hosted Libre Baskerville. Fonts ship with their SIL Open Font License texts.

The graph works entirely in the browser with a same-origin JSON file. Downloads are optional. No accounts, analytics or external application APIs are required.
